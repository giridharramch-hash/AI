System Architecture

The Extractive QA Pipeline

From natural language question to exact span extraction in four modular stages. Click any step to inspect technical details.

01

Question Input

Natural language prompt received from student or evaluator.

Input Format: Validated string up to 500 chars. Special characters preserved for tokenization.
02

TF-IDF Retriever

Sublinear TF-IDF with 1-2 n-grams ranks the corpus by cosine similarity.

Filtering: Returns top-k candidate passages. Sublinear term frequency damping prevents frequent terms from dominating.
03

DistilBERT Encoder

Passes [CLS] question [SEP] passage [SEP] through 6 transformer layers.

Contextualizing: 66M parameters, 12 attention heads. Computes rich bidirectional embeddings for every subword token in parallel.
04

QA Head & Argmax

Linear layer predicts start and end logits for every token position.

Span Selection: Answer span $(i, j)$ with $i \le j$ maximises $P(\text{start}=i) \times P(\text{end}=j)$ with max span length of 30 tokens.
Mathematical Foundations

Self-Attention Mechanism

How tokens contextualize their representations by attending to all other tokens simultaneously.

Scaled Dot-Product Attention Formula

Vaswani et al., Attention Is All You Need (2017). Each token generates a Query ($Q$), Key ($K$), and Value ($V$) vector.

Query, Key, and Value

Like a database lookup: Query is what a token is looking for; Key is what each candidate token offers; Value is the semantic content aggregated via weighted sum.

Why divide by √d_k?

For large dimension $d_k$, the dot products grow in magnitude, pushing the softmax function into regions with extremely small gradients and near one-hot distributions. Scaling stabilizes training variance.

Multi-Head Attention

Rather than computing attention once, DistilBERT runs 12 attention heads in parallel. This allows the model to jointly attend to syntactic dependencies, co-reference, and factual relations in separate subspaces.

Positional Encodings

Because self-attention operations are permutation-invariant (having no inherent notion of sequence order), learned positional encodings are added to token embeddings so word ordering is preserved.

Critical Analysis

Limitations & Future Scope

Honest reflection on extractive QA constraints and next-generation improvements.

Current System Limitations

Inherent boundary constraints of extractive span prediction on curated course notes.

  • Span Continuity: The answer must exist as a contiguous substring of a single passage. The system cannot rephrase or format bullets.
  • Multi-Hop Reasoning: Cannot combine distinct facts located in separate passages (e.g. comparing A* space complexity against BFS).
  • Confident Hallucination: A model fine-tuned on SQuAD v1.1 always returns a span, even for out-of-domain questions, sometimes with high confidence.
  • Test Set Scale: The current benchmark has 28 curated questions. While retriever Hit@1 is 100%, broader test sets with paraphrases reveal reader sensitivity.

Future Roadmap & Extensions

Architectural evolutions toward production-grade course QA and generative RAG.

  • Dense Bi-Encoder Retrieval: Replace TF-IDF sparse vectors with semantic embeddings (e.g. bge-small-en-v1.5 or Contriever) for paraphrase resilience.
  • SQuAD 2.0 No-Answer Handling: Train on unanswerable questions to enable an explicit "I don't know" threshold instead of forcing a span.
  • Course-Specific Fine-Tuning: Fine-tune DistilBERT directly on past university midterm and final exam Q&A datasets.
  • Generative RAG with Citation Grounding: Feed top retrieved spans into a quantized local generative model (e.g. LLaMA-3-8B) with passage citations.
